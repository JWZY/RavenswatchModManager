# Grimoire materials

Copied from the user-supplied `shopify-playground/grimoire` working tree for the
Ravenswatch interface experiment. This directory is self-contained.

- `paper-*.webp`, `room-grain.svg`: original parchment and room materials.
- `moonflower.svg`, `moth.svg`, `stars.svg`: original engraved illustrations.
- `font-0.ttf`: Cinzel regular (`OFL-cinzel.txt`).
- `font-2.ttf`, `font-4.ttf`, `font-6.ttf`: Cormorant Garamond italic, regular and
  semibold (`OFL-cormorant.txt`).
- `font-8.ttf`: IM Fell English regular (`OFL-imfell.txt`).
- `vendor/`: OpenPageFlip 0.7.0, its stylesheet and MIT license.

See `docs/grimoire-prototype.md` at the repository root for integration notes.
